Commands

The command tree generates this page and each page it links to. Each verb has one page with its usage, output, flags, exit codes, and agent hints.

vcs pr

Verb What it does
vcs pr status Print the state of one pull request on one line.
vcs pr create Open a pull request.

vcs issue

Verb What it does
vcs issue create Open an issue.

vcs pr

Verb What it does
vcs pr ready Take a pull request out of draft.
vcs pr draft Turn a pull request back into a draft.
vcs pr close Close a pull request with no merge.
vcs pr rebase Tick the rebase box in the body of a Renovate pull request.
vcs pr edit Change the title, the body or the base branch of a pull request.
vcs pr merge Merge a pull request.
vcs pr heal Mark and unmark the pull requests that a worker heals now, with the label ➕healing.
vcs pr tick Read every open pull request once.
vcs pr watch Poll the checks and the merge state of one pull request until both are good.
vcs pr list List pull requests, newest first.

vcs issue

Verb What it does
vcs issue list List issues, newest first.
vcs issue view Print one issue with its body and its comments.

vcs ci

Verb What it does
vcs ci failed List the red jobs of a pull request head or a commit, with the first error of each log.
vcs ci runs List CI runs, newest first.
vcs ci jobs List the jobs of one CI run.
vcs ci artifacts List the artifacts of one CI run.
vcs ci artifact get Download one artifact of a CI run, or every artifact with --all.
vcs ci log Print the log of one CI job, as the runner wrote it.
vcs ci rerun Restart a CI run.

vcs comment

Verb What it does
vcs comment add Post one comment on an issue or a pull request.
vcs comment list List the comments of an issue or a pull request.
vcs comment edit Replace the text of one comment.
vcs comment delete Delete one comment.

vcs milestone

Verb What it does
vcs milestone list List the milestones of the repository.
vcs milestone view Show one milestone.
vcs milestone create Make one milestone.

vcs issue

Verb What it does
vcs issue edit Change the title, the body, the state, the milestone, or the labels of an issue.

vcs label

Verb What it does
vcs label list List the labels of the repository.
vcs label create Make one label.
vcs label rename Change the name of one label.

vcs board

Verb What it does
vcs board list List the project boards of the repository.
vcs board view Show the cards of one board.
vcs board add Put issues or pull requests on a board.
vcs board move Move cards to a column, by column id or title.

vcs time

Verb What it does
vcs time add Log time on an issue or a pull request.
vcs time list List the time entries of one issue, or of the whole repository with no number.
vcs time total Add up the time entries of one issue, or of the whole repository with no number.

vcs stopwatch

Verb What it does
vcs stopwatch list List the running stopwatches of the caller.

vcs git

Verb What it does
vcs git commit Commit with the guard checks.
vcs git push Push with the guard checks: never a force-push, never a hook bypass.
vcs git merge Merge with the guard checks: never on main, no AI credit line in a message, no hook bypass.
vcs git rebase Rebase a branch that origin doesn't hold yet.
vcs git branch Make, switch, rename, delete, or list branches.

vcs attach

Verb What it does
vcs attach Upload files to an issue or a pull request, and optionally post one comment that shows them.

vcs session

Verb What it does
vcs session login Sign in to the web side of the forge and keep the session.
vcs session import Keep the i_like_gitea cookie of a browser session, read from standard input.
vcs session status Tell whether the kept session is still good.
vcs session logout Delete the kept session of this host.

vcs docs

Verb What it does
vcs docs gen Write one Markdown page for each verb of the command tree.

vcs site

Verb What it does
vcs site gen Build the documentation site.
