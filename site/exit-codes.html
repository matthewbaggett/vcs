Exit codes and agent hints

The command tree generates this page.

Exit codes

Code Meaning
0 The command did its work.
1 The command ran and failed, or a check of a git verb failed.
2 stopwatch list --check found a running stopwatch. It means found, not failed.
64 Usage error. The arguments are wrong.
65 The text you sent fails the prose lint. Nothing was sent.
69 No usable driver, or the driver doesn't have the call. Stop and ask.
77 The verb needs a web session, and there is none. Run vcs session login.

Agent hints

An agent is any caller that isn't a person at a terminal. The flags --agent and --human, and the variable VCS_CALLER, set the caller by hand. An agent sees one line on stderr after each run: vcs: next: <hint>. The hint tells the agent what to do for the outcome. A person never sees it.

Each verb has a hint for the outcomes ok, fail, usage, and unavailable. A verb that sends text also has lint.
